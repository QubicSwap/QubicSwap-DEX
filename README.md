## Overview

QubicSwap gives users direct access to Qubic markets and trading workflows from one app. It is built for Qubic token swaps, QX order book trading, Qubic share markets, QSwap liquidity, wallet connection, asset transfers, and fee review.

The app helps users:

- Swap Qubic tokens
- Trade Qubic assets
- Follow QX order book markets
- Explore Qubic share markets
- Access Qubic liquidity pools
- Connect with supported Qubic wallets
- Transfer supported Qubic assets
- Review Qubic, QX, QSwap, and transfer fee context before wallet confirmation

## Wallet, Transfer, And Fee Support

QubicSwap keeps supporting trading workflows close to the main app experience.

- Wallet connection through supported Qubic wallet providers
- Transaction signing through the connected wallet flow
- Qubic asset transfer workflows for supported assets
- Movement between QX and QSwap contexts when required by a trading or swap workflow
- Visible Qubic, QX, QSwap, and transfer fee context before wallet confirmation

QubicSwap does not require users to enter a seed phrase into the app.
